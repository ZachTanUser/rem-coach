# Rem Coach (test build)

A coach for Deadlock: Rem talks you through the match from what's on your screen, and the app tracks your games
(ratings, builds, full stats, reviews).

## Download

**[Download RemCoach.zip](https://github.com/ZachTanUser/rem-coach/releases/latest/download/RemCoach.zip)** (Windows 10/11, ~36 MB)

1. Unzip it somewhere that's yours, like Desktop or Documents (not Program Files).
2. Open `RemCoach.exe`. If Windows says "Windows protected your PC" (the app isn't signed): **More info → Run anyway**.
3. That's it. It finds your Steam account and Deadlock by itself. The **Rem** tab shows a checklist of what it found.

In Deadlock, use **Borderless Windowed** (Settings → Video), and turn Rem on from the Rem tab before you queue.

## Updates

The app checks for a new version when it opens and shows **Update now** at the top. One click and it updates
and reopens by itself; your games and settings stay.

It doesn't start with Windows and doesn't install anything: delete the folder to remove it.
